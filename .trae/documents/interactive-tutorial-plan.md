## 一、整体页面结构（双端同构）

每步统一骨架（Wear 450×450 圆屏示意）：

```
┌───────────────────────┐
│ 2/9 · 向左滑 = 会      │ ← 进度小字 + 本步标题（粗体一行）
│ 翻面确认后左滑…        │ ← 副文案一行（语义解释，超出省略）
│ ┌─────────────────┐   │
│ │                 │   │ ← 中部操作区（真实卡片/拼写/仿真搜索/仿真详情）
│ │      apple      │   │
│ │                 │   │
│ └─────────────────┘   │
│ ✓ 很好（做对时出现）   │ ← 绿色反馈，约 0.8s 后自动切下一步
│      跳过教程          │ ← 底部小字 Chip → 直接到完成页
└───────────────────────┘
```

引导方式 = **约束式引导**：当前步骤只开放目标手势（其余手势回调传 null 禁用），用户做不错，无需遮罩/高亮/气泡。

## 二、逐步设计（文案为最终草案，实现时照抄）

### 第 1 步 · 翻面

* 标题：`点一下卡片`　副文案：`学习时先看单词，点一下翻面看释义`

* 内容：真实卡片，正面 **apple** /ˈæpəl/ + 卡内小字"点一下看释义"；背面 `n. 苹果` + 例句

* 手势：仅开点击；完成条件：翻面

### 第 2 步 · 左滑 = 会

* 标题：`向左滑 = 会`　副文案：`翻面确认后左滑；浏览新词时左滑 = 已学过`

* 内容：apple 新卡（正面起）；**未翻面时滑动全部禁用**（与真实学习一致），翻面后仅开放左滑

* 完成条件：翻面 → 左滑飞出

### 第 3 步 · 上滑 = 不会

* 标题：`向上滑 = 不会`　副文案：`不会的词沉底重来；浏览新词时上滑 = 加入待背`

* 内容：banana /bəˈnɑːnə/ 新卡，逻辑同上改上滑

* 完成条件：翻面 → 上滑飞出

### 第 4 步 · 拼写卡

* 标题：`拼出这个单词`　副文案：`每个词过三遍：英→中→拼写`

* 内容：正面释义 `n. 苹果` + "点一下拼写"；背面真实 `SpellingPanel`（apple 逐字母乱序）

* 手势：仅开点击翻面；完成条件：拼对（拼错走面板自带抖动/改错，不计失败）

### 第 5 步 · 长按 = 错题集

* 标题：`长按卡片`　副文案：`难词长按加入错题集，随时回顾`

* 内容：apple 正面卡，仅开长按

* 完成条件：长按 → 显示"✓ 已加入错题集（演示）"后自动切步

### 第 6 步 · 双击空白 = 撤销

* 标题：`双击空白 = 撤销`　副文案：`先把卡片滑走，再双击卡片外的空白处`

* 内容：banana 新卡，开放左/上滑；滑走后卡片消失、引导文案变为"现在双击卡片外的空白"；双击后卡片从飞出方向**原路飞回**（复用 `undoReplay` 机制）

* 完成条件：卡片飞回。滑走前撤销手势不启用，防止误触

### 第 7 步 · 搜索（仿真）

* 标题：`搜索单词和词组`　副文案：`结果分左右两列，滑动切换；点条目看详情`

* 内容：仿真搜索框（静态，显示"apple"）+ 真实 `HorizontalPager` 两列可滑：左列单词 `apple /ˈæpəl/`、`application /ˌæplɪˈkeɪʃn/`；右列词组 `apple pie 苹果派`；条目样式仿真实搜索页圆角条

* 完成条件：点击任一条目

### 第 8 步 · 详情页发音（仿真）

* 标题：`点标题听发音`　副文案：`详情页里词形、派生词、词组都能点开`

* 内容：仿真详情页——顶部大标题 **apple**（可点）+ 音标 + 释义 + 简化"词形变化 / 派生词 / 相关词组"静态区块

* 完成条件：点标题 → 调用 `container.ttsSpeaker.speak("apple")` **真实发音**后切步

### 第 9 步 · 完成页（含手势速查，保留原静态版信息）

* `✓ 教程完成` + 一句 `随时可从「我的 → 使用指引」再来练习`

* 速查列表：

  * 点卡片 = 翻面看释义

  * 左滑 = 会（浏览时 = 已学过）

  * 上滑 = 不会（浏览时 = 加入待背）

  * 长按卡片 = 加入错题集

  * 双击空白 = 撤销上一张

  * 点详情标题 = 发音

* `完成` 按钮 → 返回上一页
