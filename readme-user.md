# ⌚ VocabWatch 手表背单词 · 使用指南

> 一款**直接装在手表上**的背单词应用，不用连手机也能用。
> 抬腕就能背单词，每天到点提醒你，碎片时间刷一刷，单词自然记住。

---

## 📖 它能帮你做什么

| 功能            | 说明                                                                                       |
| ------------- | ---------------------------------------------------------------------------------------- |
| 🗓️ **每日背单词** | 每天按计划推送新词，先浏览挑选，再通过「看英文想中文、看中文想英文、动手拼写」三遍加深记忆                                            |
| 🔁 **智能复习**   | 根据你的记忆情况自动安排复习时间，会的词少出现、不会的词多出现（科学的间隔重复算法）                                               |
| ⏰ **每日提醒**    | 设置每天固定时间，手表准时震动提醒你背单词，后台被清理也不怕                                                           |
| ❌ **错题集**     | 长按卡片把拿不准的词收进错题集，随时集中重练                                                                   |
| 🔍 **查单词**    | 随时搜索单词或中文，查看释义、音标和例句                                                                     |
| 📚 **开源词书**   | 内置「初中词汇」「高中词汇」共 5730 词，基于开源词典 ECDICT（MIT 许可）整理，含音标、词性、例句和翻译，可任意多选几本书混背；也支持导入自己的词书，无需复杂授权 |
| 🖼️ **个性头像**  | 长按头像即可从手表相册选一张照片做头像，长按昵称还能改名字                                                            |
| 📊 **学习统计**   | 记录连续学习天数和已学单词数，坚持看得见                                                                     |
| 🧠 **进度记忆**   | 退出后再打开，自动回到你上次离开的页面                                                                      |

## 🚀 安装步骤

1. 通过电脑把安装包（`VocabWatch-debug-日期.apk`）用 `adb install` 或手表安装器装到手表。或者使用无线adb软件安装（如甲壳虫助手）
2. 首次打开会进入**引导页**，共 4 步：
   - **选词书**：初中词汇 / 高中词汇（以后可在「词书管理」里更换，可多选或选「使用全部词库」）；
   - 每天想背的**新词数量**（默认 10 个）；
   - **提醒时间**：可当场开启，也可先跳过以后再设；
   - 完成，点「开始使用」。
3. 引导完成后进入主页，即可开始使用。

> 💡 提示：应用是为圆屏手表设计的，使用三星 Galaxy Watch 等 Wear OS 手表体验最佳。

## 🎯 操作指南

### 主页（左右两页）

手表主页可以**左右滑动**切换两个页面：

- **第 1 页 · 学习页**：顶部是 🔍 搜索入口，中间显示今日进度（如 `5/30`）和「开始学习」按钮。
- **第 2 页 · 我的页**：头像、连续学习天数、设置入口等。

转动**表冠（旋转表圈）** 或上下滑动屏幕，可以滚动页面。

### 开始背单词

1. 在学习页点击 **「开始学习」**。
2. **浏览阶段**：一张张看今天的新词。卡片**正面**是单词和音标，提示「点一下看释义」。
   - 👆 **点一下卡片**：翻到**背面**看词性、中文翻译、例句和例句翻译，再点一下翻回。
   - ⬆️ **向上滑动**：这个词「不认识」，选入今天要背的列表（只有手上这张卡会滑走，下面的卡片不动）。
   - ⬅️ **向左滑动**：这个词「已学过」，直接跳过并安排到以后复习。
   - **长按卡片**（手指按住稍久）：把词加入**错题集**。
3. 选够数量后，点击 **「开始背单词」** 进入测试。

### 测试阶段（重点手势）

| 操作               | 效果                         |
| ---------------- | -------------------------- |
| 👆 **点一下**       | 翻面看答案                      |
| ⬅️ **向左滑**       | 「会」——这个词掌握了，进入下一个          |
| ⬆️ **向上滑**       | 「不会」——稍后重新出现，多练几遍          |
| 👆👆👆 **快速点三下** | **撤销**上一次操作（点错了？三击就回到上一个词） |
| **长按**           | 加入错题集                      |

> ⚠️ 小提示：
> 
> - 「会 / 不会」需要**先点一下翻到答案面**才能滑动评分。
> - 三击撤销要**快**：在约三分之一秒内连点三下。普通的点两下翻面**不会**误触发撤销，放心使用。
> - 每个词会用三种方式考你：看英文选义 → 看中文选词 → 字母拼写，三遍都答对才算真正过关。

### 设置每日提醒

1. 进入 **「我的」→「背单词设置」**。
2. 找到 **「每日提醒」**，上下滑动 ⏰ **小时轮** 和 **分钟轮** 选择时间。
   - 转动表冠或在数字上滑动即可调整，**停在哪就是哪**，上方时间会**实时更新**。
   - 调好后**自动保存**，不用再点确认。
3. 点击 **「开启提醒」**，按提示允许通知权限即可。
   - 建议同时允许「忽略电池优化」，这样手表省电清理时也不会漏掉提醒。
4. 想关闭提醒，点 **「关闭提醒」**。

> 🌙 提醒时间支持精确到分钟（如 **08:55**），并使用系统精确闹钟，即使应用在后台被关闭、手表重启，到点也会提醒。

### 更换头像

- **换内置表情头像**：在「我的」页 **点一下头像**，每点一下切换一个表情。
- **用照片做头像**：**长按头像** → 允许访问照片 → 从相册列表里选一张 → 点击「设为头像」。
  - 相册里没有照片时，先用手机把照片同步到手表即可看到。

### 查单词

- 主页点击顶部 **🔍 搜索**，输入英文或中文即可。
- 有结果会列出单词，点进去可看**音标、词性、完整释义、词形变换、例句和翻译**，页面可上下滚动；查不到会提示「没有相关单词」。

### 错题集

- 学习时长按卡片可把词加入错题集。
- 在 **「我的」→「错题集」** 里查看所有收藏的词，并可开始**错题重练**。

### 选择词书（可多选）

- 在 **「我的」→「词书管理」** 里点词书卡片即可**勾选 / 取消勾选**，选中的书前面带 ✓ 并高亮，**可以同时选任意几本**混着背。
- 点最上面的 **「使用全部词库」** 回到全部词书混背；手动把书全部取消勾选时也会自动回到全部词书。
- 内置两本开源词书：**初中词汇**（1987 词）和 **高中词汇**（3743 词），基于开源词典 **ECDICT**（MIT 许可）整理，含双音标、词性释义、例句译文；单词顺序已**随机打乱**。
- 卡片下方可**导出**该词书，本地导入的词书还可以**删除**。

### 导入词书 / 从设备导入备份

- **词书导入**：点「词书管理」里的 **「从设备导入词书」** 按钮（常驻，不会消失），打开文件列表（显示文件大小和日期，跟搜单词结果样式一致），点 JSON 即导入。
  - 免权限：把词书文件放到手表的 `Android/data/top.southfish.engrave/files/books/` 目录；也可以授权后直接读 Download 目录——授权方式：应用内点「授权读取 Download」按提示允许，或手表「设置 → 安全与隐私 → 许可管理器 → 文件」允许本应用（就是「访问您设备上的文件」那一项）。
  - 也可以在手表的文件管理器里直接「打开 / 分享」词书文件，选择本应用导入。
- **数据恢复导入**：在 **「我的」→「数据管理」** 里点 **「从设备导入备份」**（常驻按钮），选择备份 JSON 后会弹确认（恢复会替换全部数据，确认后才执行）；选错词书 JSON 时会提示「不是数据备份文件」。
- [词典工具](https://github.com/SouthFishowo/Engrave_DictionaryConverter)

## 📅 关于「今天没学完」

- 当天的学习任务如果**没学完就到了第二天**，没完成的进度会**自动作废**，不会堆到明天让你压力山大。
- 而当天**已经学完的单词**会正常进入复习计划，不会白学。
- 「学习日」以**凌晨 4 点**为分界——熬夜学到凌晨也还算前一天的进度。

## ⚠️ 注意事项

- **滑动要干脆**：上滑/左滑评分时手势稍微快一点；手指按住卡片**慢慢拖**会被识别为「长按」，效果是把词加入错题集而不是翻卡。
- **背单词时先翻面再滑**：背单词阶段卡片正面只显示题目，点一下翻到答案面后，上滑「不会」/ 左滑「会」才生效。
- **选词书后立即生效**：在「词书管理」里点书即可勾选/取消，支持多选（✓ 高亮显示）；全部取消会自动回到「使用全部词库」，主页的总词数随之变化。
- **清除后台不丢进度**：应用被系统清理后重新打开，会自动回到你离开时的页面（搜索页 / 背单词页）；当天没背完的卡片进度也会保留，跨天才作废。
- **提醒可靠性**：开启提醒时应用会先检查通知权限，没有权限才会向你申请；已授权时不再反复弹授权或跳系统设置。建议允许「忽略电池优化」，手表重启或应用更新后提醒会自动重新安排。
- **换头像和改名字**：**长按头像**从相册选照片，**长按昵称**进入改名，输入完点键盘上的对勾保存。
- **词书内容**：内置词书基于开源词典 ECDICT（skywind3000/ECDICT，MIT License）和网络内容整理，含音标、词性、例句和翻译；单词顺序已随机打乱。
- **导入词书格式**：自定义词书需为 JSON，包含书名和单词列表（单词可带音标、释义、例句），格式不对会导入失败。

## ❓ 常见问题

**Q：到点了没收到提醒？**
A：请检查三点：① 设置里提醒是否为「已开启」；② 是否允许了通知权限；③ 在系统设置里允许本应用「忽略电池优化 / 后台运行」。手表重启后应用会自动重新安排提醒，无需手动打开。

**Q：三击撤销老是不成功？**
A：三下要连得快一点（约 0.3 秒内），手指尽量点在卡片中间、不要滑动。正常点两下翻面不会撤销，不用担心误触。

**Q：换了头像/改了设置，重开后会丢吗？**
A：不会。所有设置、头像、提醒时间都会自动保存；重开应用还会回到你上次退出的页面。

**Q：相册里选不了照片？**
A：第一次使用长按头像时请点「允许」访问照片。如果手表相册是空的，先把照片同步到手表。

**Q：一天要背多少词合适？**
A：可在「背单词设置 → 每日新词」里调整（5～50 个），建议新手从 10 个开始，养成习惯后再加量。

**Q：会占用很多电量吗？**
A：不会。提醒使用系统闹钟机制，平时应用不常驻后台，只有到点时才唤醒发一条通知。

**Q：应用被划掉/手表重启后，进度还在吗？**
A：在。重新打开应用会直接回到你上次所在的页面（比如正在背单词的页面）；当天的学习进度保留，只有跨了一天（凌晨 4 点后）没学完的部分才会重置。

**Q：切换词书后，主页的总词数变了？已学单词记录会消失吗？**
A：正常现象。只勾一本书时只统计这本书的词（初中 1987、高中 3743），勾两本时显示「2 本词书」合计 5730 词，「使用全部词库」也是全部词书合计；已学进度分别记录，不会丢失。

**Q：怎么改名字 / 换头像？**
A：在「我的」页**长按昵称**进入改名（点键盘对勾保存），**长按头像**打开相册选照片。轻点这两个位置没有反应，是为了避免误触。做了这个功能是因为后面可能会有一些计划。

**Q：选词时一直选不到目标数量？**
A：只要词书里还有没看过的词，列表会一直出词供你选，不会中途断掉；顶部显示「已选 N/目标」，选够了就进入背单词。

## 🎈 小建议

- **固定时间**：把提醒设在你每天抬腕最多的时段（如通勤、午休），更容易坚持。
- **少量多次**：每天 10 个新词 + 复习旧词，比一次背 50 个记得牢。
- **善用三击**：手滑点错别慌，快速点三下就能撤回来。
