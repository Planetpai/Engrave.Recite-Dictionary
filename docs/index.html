从查词、背词、错词复习到提醒与备份，不需要掏出手机，也不需要第二个应用。

F / 01
离线查词
中英双向模糊搜索，英文前缀/包含匹配 + 中文释义检索，结果按考频排序；详情含音标、词性、例句，并自动标注过去式、分词、比较级等词形变化。
F / 02
卡片背词
正面单词与音标，点击翻面查看释义例句；左滑「会」、上滑「不会」，三击撤销防误触。新词当天连刷英文、释义、拼写三遍。
F / 03
错题本
记错的词自动收录，搜索历史可一键加入；左滑管理、批量删除，薄弱词汇反复回炉。
F / 04
学习提醒
每日定点提醒，滚轮选时精确到分钟；使用精确闹钟并引导电池优化白名单，深度睡眠后也不迟到。
F / 05
词书管理
内置考纲词书 + JSON 自定义导入与导出，多书并行激活；删除操作二次确认，名称与后果写得明明白白。
F / 06
备份与恢复
学习数据本地 JSON 备份与恢复，会话与导航状态自动保存。数据在你手里，不在任何人的服务器上。
F / 07
个性化
从手表相册选择头像（长按进入）、自定义昵称；首次启动引导页，三步开始学习。
